# Trabajos universitarios

Repositorio de **referencia**: cada carpeta contiene el HTML público que se enlaza desde el `.docx` entregado.

El entregable oficial de cada materia es el archivo `.docx` (entregado por la plataforma de la universidad).
Aquí solo se publica el HTML interactivo que el `.docx` cita como apoyo.

## Trabajos

- **[estadistica-multivariada](https://XiaoLuxtl.github.io/trabajos-universidad/estadistica-multivariada/)** — Menú interactivo: conceptos básicos de estadística multivariada y su relación con la inferencial. Actividad Formativa 1.
- **[desarrollo-sustentable](https://XiaoLuxtl.github.io/trabajos-universidad/desarrollo-sustentable/)** — Infografía interactiva: interconexión entre sistemas naturales e ideologías económicas, sociales y políticas. Tarea 1-3.
